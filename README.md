# Human Detection System 👁️

## 📌 Description

This project is a real-time human detection system built using computer vision techniques. It detects human presence from a live webcam feed and highlights them with a bounding box.

## 🚀 Features

* Real-time human detection
* Works with laptop webcam
* No dataset required
* Lightweight and efficient

## 🛠️ Technologies Used

* Python
* OpenCV

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the project:
   python main.py

## 📷 Output

Detects humans and draws a green rectangle around them in real-time.
